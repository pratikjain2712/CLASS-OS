# ClassOS — Question Paper Generator: Implementation Plan

## Context

Arihant Educare is primarily interested in question paper generation. The feature must support multiple publishers (Arihant, DC Pandey, HC Verma, etc.) with their books stored as PDFs in the platform. A teacher selects class, subject, publisher, chapters (one/many/all), difficulty, and a mark template — and gets a ready-to-print paper. Two generation modes: **Bank** (pulls from stored questions) and **AI** (generates fresh questions from chapter content, costs credits). AI-generated questions get saved back to the bank for future reuse.

**Example teacher flow:**
> Class 8 → Maths → Arihant → Hard → 40-mark template → Chapters 1, 3, 5 → Generate

## Database Schema

### Organisation Hierarchy

```sql
institutes
  id, name, logo_url, subscription_plan, created_at

branches
  id, institute_id, name, city, address
  -- e.g. "Arihant Educare — Pune", "Arihant Educare — Mumbai"

  id, teacher_id, branch_id, class (int), section, subject
  -- Teacher A → Branch A → Class 8 → Section A → Maths
```

**Access control rules (strict):**
- Teacher sees only papers they created (`papers.created_by = teacher_id`)
- Branch admin sees all papers within their branch
- Institute admin sees all papers across all branches
- Papers have NO cross-teacher visibility by default — no soft sharing in V1

### Publishers & Content Library

```sql

  id, name, logo_url, created_at

  id, publisher_id, title, subject, class (int), board, edition

  id, book_id, chapter_number, chapter_name,
```

### Paper Generation Sources

```sql
paper_generation_sources    -- what content a paper was generated from
  id, paper_id
  source_type     -- chapter_select | subtopic_select | page_range | page_upload | custom_text
  chapter_ids (uuid[])       -- for chapter_select
  subtopic_ids (uuid[])      -- for subtopic_select
  page_ranges (jsonb)        -- for page_range: [{chapter_id, ranges: "1-10,13-15"}]
  uploaded_file_url          -- for page_upload (stored in R2, OCR processed)
  custom_text                -- for custom_text paste
  extracted_content (text)   -- processed content used in AI prompt (post-filter)
```

Page range format: comma-separated ranges per chapter — `"1-10,13-15"` means pages 1–10 and 13–15.
Parsed server-side: `[(1,10), (13,15)]` → filter `chapter_chunks` by `page_number` within those ranges.

Requires `page_number` on `chapter_chunks`:
```sql
chapter_chunks
  id, chapter_id, chunk_index, content, embedding (vector(1536))
  page_number (int)   -- which book page this chunk came from
```

## PDF Ingestion Pipeline

```
Admin uploads PDF → Cloudflare R2
  ↓ Background job (Celery)
PDF text extraction (pdfplumber) + image extraction (pdfplumber/pymupdf)
  ↓
Chapter detection (by heading patterns OR admin marks boundaries)
  ↓
Text → 500-token chunks per chapter
  ↓
Chunks → embeddings (Claude / OpenAI embeddings API)
  ↓
Store in chapter_chunks with pgvector
  ↓
Extracted diagram/figure images → stored in R2, linked to chunks
  ↓ (optional Phase 2)
Auto-extract existing questions from publisher PDFs using AI
→ store in questions table tagged source_type='publisher_bank'
→ questions with diagrams get media[] populated with R2 image URLs
```

## AI Diagram Generation Pipeline

When AI generates a question requiring a diagram:
```
AI returns: { question_text, diagram_type, diagram_code, ... }
  ↓
Server receives diagram_code in sandboxed container (Docker)
  Geometric/Trig → render SVG
  Physics/Graphs → run matplotlib Python → PNG
  Chemistry      → parse SMILES → RDKit → PNG
  ↓
Rendered output stored in Cloudflare R2
  ↓
question.media[] populated with R2 URL
question.question_text uses [[MEDIA:id]] placeholder
  ↓
PDF generation embeds image inline at placeholder position
```

**Security:** All AI-generated code runs in an isolated Docker container with no network access, 10s timeout, memory limit.

## Paper Generation Logic

### Bank Mode
```sql
SELECT * FROM questions
WHERE chapter_id IN [selected_chapters]
  AND difficulty = :difficulty
  AND question_type = :section_type
  AND marks = :section_marks
  AND id NOT IN (
    SELECT question_id FROM question_usage
    WHERE batch_id = :batch_id AND asked_on > NOW() - INTERVAL '6 months'
  )
ORDER BY usage_count ASC, RANDOM()
LIMIT :section_question_count
```
Warn (don't block) if a question was asked before. Teacher can override.

### AI Mode
```
1. RAG: similarity search on chapter_chunks using question topic embedding
2. Build prompt:
   - Retrieved chapter content chunks
   - Mark-level pattern (board-specific: 4-mark SA = explain with example, 3 points)
   - Difficulty, question_type, count
3. Call Claude API → receive JSON: { question, options, answer, solution, concept_tags }
4. Save to questions table (source_type = 'ai_generated')
5. Deduct 1 credit per question from institute_credits
6. Log in credit_transactions
7. Return questions for paper
```

### Mark-Level Pattern Config (stored, not hardcoded)
```
1-mark  → MCQ / one-word recall
2-mark  → VSA: define, state, name — 2-3 lines
3-mark  → Short answer: list 3 points or explain briefly
4-mark  → SA: explain with example
5-mark  → Long answer: derive / describe / compare
8-mark  → Full derivation / case study
JEE     → Numerical + multi-correct MCQ
NEET    → Application-based MCQ
```

```
Step 1: Board + Class + Subject + Publisher  (cascading dropdowns)
Step 2: Choose source
          ○ Full chapters    → multi-select checklist + "Select All"
          ○ Subtopics        → drill into chapter → pick subtopics
          ○ Page ranges      → select chapter → type "1-10, 13-15"
                               (multiple chapters each with own range)
          ○ Upload pages     → drag/drop photo or PDF pages (OCR on upload)
          ○ Paste notes      → free text box
        (sources combinable — e.g. Chapter 2 pages 1-10 + uploaded 3 pages)
Step 3: Pick Template                        (cards: 10 / 20 / 40 / 80 / Custom)
Step 4: Mode + Difficulty
          Mode: Bank | AI Generated
          Difficulty: Easy | Medium | Hard | Mixed
          → Show available question count BEFORE generating
          → Show credit cost if AI mode selected
Step 5: Generate
          → Bank: instant result
          → AI Bank: instant if pre-built; async job + notification if gap
Step 6: Review questions
          → Swap: filter replacement by chapter/subtopic/difficulty/type
          → "Already asked to Class 8A" warning badge per question
Step 7: Preview (in-browser) + Export
          → PDF: question paper + answer key as separate download
          → DOCX export
          → Set A + Set B option
          → Watermark with institute + branch name
          → QR code auto-embedded top-right corner
```

## Language Support

- `language` field on `questions` and `papers`: en | hi | mr | sa | fr
- `bilingual` flag on papers — English instructions + regional language questions
- PDF font switching: Noto Sans Devanagari for Hindi/Marathi/Sanskrit; standard Latin for French/English
- AI generation prompt: "Generate this question in [LANGUAGE]. Use proper [LANGUAGE] script."
- Sanskrit flagged as beta — AI quality limited; human review required before adding to bank
- Paper headers localised via `institute_print_config.header_template` (per-language strings)

## Paper Export Features

- **Set A + Set B**: same questions, shuffled order within each section, auto re-numbered
- **Answer Key PDF**: companion PDF generated alongside question paper (answer + solution per question)
- **Print settings per export**: font size, answer space lines, margins, question numbering style
- **Institute header**: logo + institute name + exam metadata pulled from `institute_print_config`
- **Draft auto-save**: paper saves on every question swap; "Resume draft" on dashboard

## AI Bank Architecture

Two pre-built banks, both reviewed by ClassOS team before going live:

| Bank | Source | Review |
|------|--------|--------|
| **Publisher Bank** | OCR + AI extraction from publisher PDFs | ClassOS team approves each question |
| **AI Bank** | ClassOS team generates in-house using Claude API in bulk | Reviewed before live |

**Teacher-facing AI Generated mode flow:**
```
Request: 5 Hard SA questions, Chapter 3
  ↓
Check AI Bank → found? → serve instantly, deduct credits
  ↓ not found
Queue real-time Claude API generation job
  → question generated + auto-reviewed → added to AI Bank
  → teacher notified (email + in-app) when ready
```

**Credit system:**
- `credits_reserved` on job start, `credits_consumed` on success, released on failure
- Failed jobs refund credits automatically — no manual intervention needed

### The AI Learning Loop

```
High-acceptance questions (swap rate < 5%)
    ↓
Pulled as few-shot examples in AI generation prompts
    ↓
AI generates questions more like accepted ones
    ↓
Acceptance rate improves → more examples → loop continues
```

After 6 months + 10,000 swap events: enough signal to fine-tune a
question generation model specifically for Indian curriculum. The
`question_events` table is a preference dataset being built passively.

## Verification

1. Upload a sample book PDF → confirm chapter extraction, chunk storage, page_number on each chunk
2. Bank-mode generation for 40-mark template, Chapters 1+3+5 (page range 1-10,13-15) → marks sum to 40, proportional chapter distribution
3. AI-mode generation → credits_reserved on start, credits_consumed on success, released on failure; question saved to AI Bank
4. Same question asked to same batch twice → warning badge appears in Step 6
5. Swap a question → question_event recorded with swap_reason; quality score updated
6. Abandon at Step 4 → generation_funnel_event logged with action=abandoned, time_spent_sec
7. Platform admin: coverage gap map shows shortfall chapters; quality tier distribution visible
8. PDF export → QR top-right, watermark diagonal, answer key as separate download, Set B shuffled correctly
9. Teacher A cannot see Teacher B's papers; Branch A cannot see Branch B papers
10. Institute with expired subscription → bank access blocked, credit balance still visible
